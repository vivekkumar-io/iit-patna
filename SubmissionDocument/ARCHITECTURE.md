## High-level architecture

```
Documents (PDF/TXT/DOCX)
        │
        ▼
┌───────────────────┐
│  Document Loader  │  ingestion/loader.py
└─────────┬─────────┘
          ▼
┌───────────────────┐
│     Chunker       │  ingestion/chunker.py
└─────────┬─────────┘
          ▼
┌───────────────────┐
│   Embeddings      │  ingestion/embedder.py
└─────────┬─────────┘
          ├──────────────────────┐
          ▼                      ▼
┌───────────────────┐    ┌───────────────────┐
│  ChromaDB Vector  │    │    BM25 Index     │
│      Store        │    │                   │
└─────────┬─────────┘    └─────────┬─────────┘
          │                        │
          └──────────┬─────────────┘
                     ▼
          ┌───────────────────────┐
          │   Hybrid Retriever    │  retrieval/hybrid_retriever.py
          │   (Vector + BM25)     │
          └──────────┬────────────┘
                     ▼
          ┌───────────────────────┐
          │      Reranker         │  retrieval/reranker.py
          └──────────┬────────────┘
                     ▼
          ┌───────────────────────┐
          │   Context Builder     │  generation/guard.py
          └──────────┬────────────┘
                     ▼
          ┌───────────────────────┐
          │  LLM + Chat Memory    │  generation/chain.py
          └──────────┬────────────┘
                     ▼
          ┌───────────────────────┐
          │   Streamlit UI        │  app/main.py
          │  Welcome → Chat       │  app/ui/welcome.py, app/ui/chat.py
          │  Answer + Sources     │
          └──────────┬────────────┘
                     │
                     ▼
          ┌───────────────────────┐
          │   Session Logger      │  util/logger.py
          │  (cross-cutting)      │  → logs/ (per app run)
          └───────────────────────┘
```

**Logger scope:** `util/logger.py` is used across **ingestion**, **retrieval**, **generation**, and the **app** to record pipeline steps, retrieved chunks, LLM prompts/responses, and errors in timestamped files under `logs/`.

## User flow

1. **Welcome page** — Project overview; user clicks **Start Conversation**
2. **Chat UI** — Sidebar shows knowledge scope; user asks questions in the chat input

## Query routing logic

1. **Greeting** — Short hello reply, no retrieval
2. **Casual intro** — Instant local reply (name/city), no retrieval
3. **Policy question** — Full RAG pipeline with sources
4. **Memory question** — Answered from chat history when possible

---

## Data flow for policy questions

```
Welcome page → Start Conversation
  → User query
  → should_search_documents()
  → rewrite_follow_up_question() using memory
  → hybrid retrieve (top-k)
  → rerank (top-n)
  → format_context_for_llm()
  → LLM generation
  → get_source_list()
  → UI displays answer
  → util/logger.py records full flow to logs/
```
